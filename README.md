## ⚡ MISSION MANIFEST

SkyWOW is not a dashboard—it is a **Neural Operating Layer** for airport management. Built on the principles of **A-CDM (Airport Collaborative Decision Making)**, it replaces manual gate management with a recursive, AI-driven cascade engine that optimizes every second of the ground-to-air transition.

### 🎯 TACTICAL CAPABILITIES

- **🧠 Neural Dispatch Engine**: A recursive optimization algorithm that handles gate conflicts, emergency cascades, and VIP priority shifts in real-time.
- **🧊 Glassmorphism Tactical UI**: A high-fidelity "Mission Control" interface built with nested glass layers, reactive neon HUDs, and kinetic typography.
- **🛰️ Global Telemetry Pulse**: A custom system heart-beat that synchronizes flight states, ground-crew readiness, and terminal schedule data.
- **🔐 Intelligence RBAC**: Production-grade authentication via NextAuth v5, ensuring secure tactical access for Admin and Ground Crew nodes.

## 🚀 OPERATIONAL DEPLOYMENT

### 1. Initialize Neural Link
```bash
git clone https://github.com/JVliyanarachchi21/SkyWOW.git
cd skywow-app
npm install
```

### 2. Hydrate Tactical Core
```bash
npx prisma migrate dev
node src/scripts/seed.js
```

### 3. Launch Mission Control
```bash
npm run dev
```
