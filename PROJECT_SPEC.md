# Project Specification: SkyWOW (Intelligent Airport Management System)

## 1. Introduction
SkyWOW is a high-performance, AI-integrated Airport Management System designed to showcase advanced full-stack development capabilities. It transcends standard CRUD applications by incorporating real-time data simulation and intelligent decision-making.

## 2. Core Modules

### A. Flight Operations (Real-time)
- Dynamic flight board (Arrivals/Departures).
- Real-time status updates (Delayed, On-Time, Boarding).
- Conflict detection for overlapping schedules.

### B. Smart Gate Allocation (AI-Driven)
- AI assistant to suggest gate assignments based on flight duration and aircraft type.
- Drag-and-drop interface for manual gate management.

### C. Passenger & Baggage Tracking
- Simulated passenger flow tracking.
- Baggage claim status synchronization.

### D. Control Tower Dashboard
- High-level KPIs (Total Flights, Gate Occupancy, Delay Rates).
- Interactive world map showing flight origins/destinations.

## 3. Tech Stack Requirements
- **Frontend**: Next.js 14 (App Router) + TypeScript.
- **Backend**: Next.js Server Actions + Prisma ORM.
- **Database**: PostgreSQL (Relational).
- **AI**: Google Gemini Pro API.
- **Styling**: Tailwind CSS + Framer Motion (Animations).

## 4. Visual Identity
- **Theme**: Dark Mode (Airport Control Room aesthetic).
- **Colors**: Deep Midnight Blue (#0a0a20), Neon Cyan (#00f2ff), Alert Amber (#ffaa00).
- **Typography**: Inter (Clean, readable sans-serif).
